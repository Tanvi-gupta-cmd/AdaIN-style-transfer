# 🎨 AdaIN Neural Style Transfer

### Transform Your Images with Artistic Styles Using Deep Learning

AdaIN Style Transfer is a deep learning-based application that transforms the visual appearance of a content image by applying the artistic style of another image. It uses **Adaptive Instance Normalization (AdaIN)** to combine the content and style representations, generating a stylized output image.

The project demonstrates the practical application of computer vision and deep learning for AI-powered artistic image generation.

* ⚡ **Adaptive Instance Normalization** — Uses AdaIN to align feature statistics between content and style representations.

## 🧠 What Is AdaIN?

**Adaptive Instance Normalization (AdaIN)** is a technique used in neural style transfer to adapt the feature statistics of a content image to those of a style image.

It adjusts the channel-wise mean and variance of content features to match those of style features.

This allows the model to preserve the structure of the content image while transferring the visual characteristics of the reference style.

## ⚙️ How It Works

1. **Upload Content Image:** Select the image whose structure you want to preserve.
2. **Upload Style Image:** Select an artwork or reference image containing the desired style.
3. **Feature Extraction:** A neural network extracts feature representations from both images.
4. **Style Transfer:** AdaIN aligns the content features with the style features.
5. **Image Generation:** The transformed features are decoded into a stylized image.
6. **View Result:** Display or save the generated artistic output.
